# 回归测试集

把口头验收固化成可重复用例。改了 `SKILL.md` 或 `sources.md` 后，拿这些场景各跑一遍，确认判断路径没退化。每条列"输入 + 应触发的机制 + 期望行为"，不写死具体结论（真实转会状态会变，联网为准）。

## 1. 用户不给信源，只说"X 要去 Y"
- 机制：信源由系统主动检索、不追问用户。
- 期望：正常启动、建报道场；不因"没信源"直接判存疑。

## 2. 用户记错成"Romano 爆料"
- 机制：立场三——用户信源与检索冲突时以检索为准。
- 期望：点明"你说是 X 说的，但我查到是 Y / 没查到 X 这么说"，不直接采信用户口中的信源。

## 3. 聚合站引用可靠记者但追不到原文
- 机制：聚合档 + 二手压档 + 独立性分级④。
- 期望：追不到原始一手 → 按"不可核实二手"压「存疑」封顶，不按被引记者的高档给。

## 4. 买方英语媒体一致、卖方德语可靠源否认
- 机制：双边检索硬规则 + 信源分歧 + 采样偏差防护。
- 期望：真实性封顶「待证实」，插信源分歧对照表；德语卖方源权重不被英语源数量压过。这是踩过的坑（迪奥曼德）。

## 5. 一周前 Here we go，后来交易告吹
- 机制：矛盾裁决——时间不同=演进。
- 期望：较新的"告吹"覆盖较早的 Here we go；旧报道真实性"当时可靠"，时效性=「已被推翻」。

## 6. 金额正确但阶段被夸大
- 机制：主张核对（阶段）+ 命题粒度 + 硬细节不能跨阶段。
- 期望：指出"金额对、阶段不对"，真实性不因金额准就给高档；命题锁定在真实阶段（如"在谈"非"已签"）。

## 7. 关窗期的非自由身即时加盟传闻
- 机制：窗口判定 + 例外。
- 期望：标「窗口已关」（即时注册不可能），但说明"可谈下个窗口/预签"；若是自由身则不适用。

## 8. 中国球员留洋，需要中外双方源
- 机制：中文源第五节 + 混合场景双边检索 + 留洋时效窗口取舍。
- 期望：中方(俱乐部/经纪人)+海外接收方都查；时效按"实际在哪边注册"那侧窗口判。

## 9. 多家报道实际都来自同一采访
- 机制：独立性分级②（同一表态多家转述）。
- 期望：不当多源印证，按那**一个**源的档判，不叠加、不因"很多家报了"上顶档。

## 10. 同时存在同级、同时间窗的真实分歧
- 机制：矛盾裁决——真分歧。
- 期望：真实性封顶「待证实」，两边观点摊开、不选边，插分歧对照表。

## 附加自检（每条都该满足）
- 真实性、时效性**分开报**，没有合成一个总分。
- 输出列了「买方侧检索」「卖方侧检索」，一侧无结果也写了。
- 有「本次判定命题」行。
- 有查证时间。
- 无网时真实性≤待证实、时效性=无法核实，且显式声明降级。
