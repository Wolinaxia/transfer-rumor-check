# 信源分级 & 判定数据表

> 这是 transfer-rumor-check skill 的**数据层**。`SKILL.md` 是判断逻辑，本文件是逻辑引用的数据：信源怎么归档、哪些算硬细节、转会窗口日历、中超/中甲另一套源。
>
> **为什么单独成文件**：逻辑稳，数据会变（哪家算稳机构、窗口日期每年调）。更新只动本文件，不碰 `SKILL.md`。产品化时这张表就是规则层能直接读的配置。
>
> **判定靠特征不靠人名**——下面列的是"怎么认出这一档"的可观察特征，人名只是举例，不是白名单。名字会过时，特征不会。

---

## 一、机构基准档（主维度，定起始档位）

判一条传闻，先看**承载它的机构/账号**是哪一档，落一个起始真实性档位。起点整体偏保守——默认不信，好消息要靠信号往上挣。

### 档 1 · 官方档 → 封顶「已官宣」
已经不是"传闻"，是事实。命中任一即是：
- 俱乐部/联赛**官网域名**发布（arsenal.com、realmadrid.com、premierleague.com 等）
- 平台**认证**的俱乐部官方账号、球员本人认证账号发布的官宣体
- "official" / "官宣" / "签约仪式" / 正式新闻稿口吻 + 合同期限明确

→ 落「已官宣」，**不参与后续任何调节**（它已经封顶）。

**⚠️ 三级区分——别把"官员开口"当成"官方官宣"**：
1. **俱乐部正式完成公告**（官网/认证账号的签约新闻稿）→ 这才是「已官宣」。
2. **俱乐部官员公开确认**（体育总监/主帅采访说"我们在谈他""有兴趣"）→ **强一手证据**，但**只按他确认的那个阶段判**——他说"在谈"就是「谈判中」（时效进行中），不是"已成"。别把"官员承认在追"读成"转会将成"。
3. **记者称"俱乐部内部人士表示"**→ 这是**记者报道**（按记者/机构档判），**不算官方**，别当成俱乐部开口。

### 档 2 · 稳机构档 → 起点「高可信」
有**编辑审核**、有**信誉成本**（登错要负责）的专业机构。特征：
- 独立域名 + 机构署名 + 有编辑部
- 转会领域公认可靠：**The Athletic、BBC Sport、Sky Sports、L'Équipe、Fabrizio Romano（作为机构级信源时）、Guardian、Bild（德）、Gazzetta dello Sport / Sky Italia（意）、Marca / AS / Relevo（西，注意 Marca/AS 有主队倾向，见备注）**
- 报道带记者实名 + 通常给可证伪细节

→ 起点「高可信」。备注：Marca、AS、Mundo Deportivo 这类西班牙报有明显主队（皇马/巴萨）倾向，报自家目标球员时可信度打折，报中立第三方转会时正常。

### 档 3 · 一般媒体档 → 起点「待证实」
有机构但够不上"公认可靠"，或大媒体的无署名跟进：
- 地区性/单一联赛小媒体、体育门户的编译跟进
- 大媒体但**这条没有一手记者署名**（"综合报道""据悉"）
- tabloid 小报的转会版（Sun、Mirror、Daily Mail 的转会传闻——量大、真假混杂）

→ 起点「待证实」。

### 档 4 · 聚合搬运档 → 起点「存疑」
无独立信息，靠转载别人的：
- 内容主体是"据 XX 报道""外媒称"，无自己的采访/信源
- 聚合站、搬运号、翻译搬运（把外媒机翻+加戏）
- 微博/懂球帝/直播吧等中文站转国际传闻时，**默认按此档**，但真正要做的是**穿透它去认原始外媒源**（见"中文源处理"）

→ 起点「存疑」。**关键**：聚合源本身不是判断对象，要追它"转的谁"——追到一手就按一手档，追不到才停在存疑。

### 档 5 · 营销号 / ITK 档 → 起点「大概率假」
博流量的匿名爆料，转会传闻里的最大噪音源：
- 匿名/化名、无机构挂靠、无编辑责任
- 标题党格式：【重磅】【官宣倒计时】+ 大量感叹号 + "转发扩散""关注我第一时间"
- 自称"in the know / ITK / 内部消息"但从不给可核对细节
- 蹭大牌 + 制造对立情绪（"彻底闹翻""愤然离队"）

→ 起点「大概率假」。

## 二、个人信源档（并入同一把尺子，不是独立白名单）

个人跟机构走**同一套档位尺子**。判一个署名记者，落这三档之一：

### 个人锚点档（唯一享"托底特权"的一档）
行业共识级、可信度能盖过其所属机构的极少数。特征：
- 有**极稳定的专属信号**且圈内公认（标杆 = **Fabrizio Romano 的「Here we go」**——他只在交易全部敲定才发这句，历史命中率极高）
- 在**可确认的本人账号**首发

→ **本人首发即托底到「极可靠」，不因"机构还没跟进正式报道"被压回**。这是唯一的托底特权。
→ ⚠️ 注意区分：Romano 发普通进展（"advanced talks""close"）时**不触发**「Here we go」特权，按稳机构档 + 硬细节正常判。只有那句确定性信号才享托底。

### 稳记者档（等同其所属机构档，不额外托底）
实名 + 长期挂靠稳机构 + 履历稳定的转会记者。特征：
- 真实姓名 + 明确挂在某稳机构名下（如 David Ornstein @ The Athletic、Florian Plettenberg @ Sky Germany）
- 长期专注转会、少发空消息

→ 待遇 = **等同其所属机构档**（多数是稳机构档，起点「高可信」）。不额外托底，也不折损——"他发的" ≈ "他机构发的"，靠机构信誉背书。
→ 这一档是设计关键：Ornstein 这种"极稳但不到 Romano 传奇级"的记者落这里，靠"稳机构+硬细节"就能到「极可靠」，不需要给他 Romano 级特权，也不当他不存在。

### 普通记者 / 自媒体档
实名但无稳机构挂靠，或挂靠的机构本身够不上稳机构：
- 自由撰稿人、个人博主、无编辑审核的自媒体
→ 按其内容特征走一般媒体档或更低，无任何加持。

## 三、可证伪硬细节（跨档加权信号，+1 档封顶）

带下列**具体、可事后核对**的细节，说明信源在拿信誉背书（营销号不敢写这么实）→ 真实性 **+1 档**。多个硬细节**不叠加**，最多 +1（防"堆一堆细节刷分"）。

算硬细节的（可证伪）：
- 具体**转会费**数字（含结构：固定+浮动、分期）
- **合同年限**（5年、到2030）
- **买断条款 / 解约金**具体数字
- **医疗/体检**的时间地点（"周三在米兰体检"）
- 明确**进展节点**："个人条款已谈妥""已飞抵当地""已签字""待官宣"

**不算**硬细节的（张口就来、不可证伪）：
- 纯态度/意向："有意""关注""密切留意""是引援目标"
- 模糊金额："巨额报价""天价"
- 情绪化描述："铁心要走""梦想加盟"

**升档资格（满足才触发 +1，防假细节刷分）**：
- 硬细节须来自**可追溯的一手源或一般媒体以上**，营销号给的孤立数字不算。
- 须形成**可核对的承诺链**（费用+结构+阶段互相印证），不是随口一个数。
- **不同可靠来源的金额结构明显冲突时，不触发升档**（说明细节本身没坐实）。
- 硬细节只提升"**该报道掌握真实信息**"的可能性，**不能跨阶段**——有再多细节也不能把"谈判中"推成"必然成交/已签约"。阶段由主张核对和实际进展定，不由细节数量定。

## 四、转会窗口日历（联网优先，离线仅兜底）

判时效性先看"现在开窗没有"。**窗口日期每年、每个协会、不同性别赛事和注册类别都会微调——每次查证都应联网核实涉事联赛当季的精确注册窗口**，优先联赛/足协/FIFA 官方信息，不把旧日历当当前事实。

**离线大致参考**（仅在无网络时做有限判断用，不能替代联网核实）：
- 主流欧洲**夏窗**：通常约 **6 月中 ~ 9 月初**
- **冬窗**：通常约 **1 月初 ~ 1 月底**

例外与边界（这些比"开没开窗"更重要）：
- **关窗** ≠ 不能运作：关窗后非自由身通常无法**立即注册**，但**可以谈下个窗口的交易、可以预签**。所以"窗口已关"只用于传闻声称**即时完成/注册**、且无明确例外时。
- **自由身例外**：合同到期的自由身球员可在关窗期签约，不受一般窗口限制。
- **预合同**：部分联赛允许合同最后半年与他队签预合同（次年生效）。
- **租借召回**：特定窗口/条款下可提前召回租借球员。
- **不得把欧洲日历套给中超**（第五节），也不得仅凭"大致开窗"就省略联网核实精确日期。

## 五、中超 / 中甲 / 中国球员传闻（另一套一手源）

国际传闻里中文站只当"转谁"的透明指针（追外媒源按外媒档）。但**主体是中超/中甲球队或中国球员**时，中文源成为需要独立分级的一手对象——国内权威体系和英文圈是两套。

### 中国足球语境的信源档（同样靠特征，不锁人名）
- **官方档**：俱乐部官方公众号/微博、中国足协官网、中超公司公告 → 「已官宣」
- **稳源档**：有编辑体系的主流体育媒体 + 公认可靠的持证跟队记者（如《足球报》体系记者、长期专注某队的实名跟队记者）→ 起点「高可信」
- **一般档**：地方体育媒体、门户体育编译 → 「待证实」
- **搬运/营销档**：无信源的"某足球自媒体"、贴吧爆料、蹭流量营销号 → 「存疑」/「大概率假」

### 中国语境的特有注意点
- **国字号/归化/限薪令**等政策变动常影响转会真实性，一手源常是足协/俱乐部而非记者
- 中超转会窗与欧洲**不同步**（另有自己的注册窗口期），判时效性别套欧洲日历，需单独核实当年中超窗口
- 中国球员**留洋**传闻 = 混合场景：中方俱乐部/经纪人是一手源之一，海外接收方按国际体系判，两边交叉验证

## 维护须知

改这张表时：
- 增删机构/记者：改对应档的"特征"或"举例"，不动 `SKILL.md`
- 每年窗口期变化：只更新"四、转会窗口日历"的日期
- 别把这张表拆得更碎——机构档 + 个人档 + 硬细节 + 窗口 + 中超，五块放一个文件是这个规模最好维护的形态
